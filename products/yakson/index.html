개발 중인 복약 보조 장치 PoC

YAKSON

YAKSON은 약봉투 배출과 사용자의 복용 확인을 구분해 기록하도록 개발 중인 복약 보조 장치 PoC입니다.

약을 처방하거나 실제 복용을 자동 판정하지 않습니다. 현재는 연결 약포의 이송·절단과 미수령 약포의 하단 보관 경로를 디지털로 검토 중입니다. 아래 기능은 개발 목표이며, 완성 외관과 실물 반복 시험은 아직입니다.

현재 기구 동작 검토 보기 ＋

미수령 약포를 하단에 보관하고 다음 회차 한 봉을 제시하는 경로를 살핀 디지털 후보입니다. 완성 외관·실물 반복 작동·제조 적합성은 검증 전입니다.

개발 중인 기능

  • 복약 시간 알림
  • 버튼·센서 기반 복약 이벤트 기록
  • 미복용·지연 복용 관찰 로그
  • 보호자 확인 알림
  • 기기 연결·배터리 상태 확인
  • 앱 연동
  • 사용 리포트
  • 가정 돌봄 테스트

활용 예시

약봉투를 꺼내는 과정을 살필 때

정해진 시간에 연결 약포에서 한 회분을 이송·분리해 제시하는 흐름을 검토합니다. 약봉투가 나왔다는 기록과 사용자가 복용을 확인한 기록은 구분합니다.

현재 범위

복약 보조 장치 PoC입니다. 화면과 영상은 디지털 검토본이며 실물 반복 작동·의료기기 분류·가정 배포는 검증 전입니다.
