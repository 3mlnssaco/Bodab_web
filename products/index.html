01 / Personal health app

UniQdata

UniQdata는 흩어진 건강기록, 일상 로그, 루틴을 한 화면에서 읽고 다음 행동을 준비하게 하는 개인 건강관리 앱입니다.

MediQ와 MindQ는 UniQdata 안에서 열리는 인앱 경험입니다. 사용자는 하나의 앱에서 진료 준비, 마음 기록, 건강 루틴을 자연스럽게 오갑니다.

  • 건강기록 한눈에 보기
  • 일상 로그와 루틴
  • 진료 전 질문 준비
  • 동의와 접근 확인

MediQ: 진료 전후 기록 · MindQ: 마음·컨디션 일지

02 / Research workspace

UniQLab

UniQLab은 연구자와 기관이 참여자 관리, 동의 현황, IRB 문서 업무를 더 매끄럽게 운영하도록 돕는 제품입니다.

개인 앱과 달리 연구팀과 기관을 위한 업무 제품입니다. 반복되는 문서, 참여자 상태, 협업 흐름을 한 곳에서 보이게 합니다.

  • 연구 프로젝트 준비
  • 참여자 조건 관리
  • 동의 현황 확인
  • IRB 문서 보조
  • 기관·연구자 권한
  • 데이터 접근 기록
  • 방문 일정 확인
  • 운영 리포트
UniQLab 알아보기 ↗

개인이 연구 참여와 공유 범위를 선택한 뒤 연결되는 활용처입니다.

03 / Care app

Bodab

Bodab은 고령자와 가족이 복약, 일정, 생활 상태를 함께 챙기는 가족 돌봄 앱입니다.

부모님의 하루를 보호자가 멀리서도 이해할 수 있게 합니다. 알림보다 중요한 것은 가족이 같은 상황을 보고 대화할 수 있는 경험입니다.

  • 보호자·가족 초대
  • 복약 일정과 복용 체크
  • 병원 방문·돌봄 일정 관리
  • 식사·수면·컨디션 생활 기록
  • 이상 징후와 메모 남기기
  • 보호자 공유 알림
  • 돌봄 요청과 확인
  • 지역 활동·사회참여 카드

04 / Medication device

YAKSON

YAKSON은 복약 시간을 챙기고 가족에게 확인 흐름을 이어주는 복약 보조 디바이스입니다.

약을 처방하거나 판단하는 제품이 아닙니다. 복약 시간을 알리고, 복용 확인 경험을 앱과 연결해 보호자가 안심할 수 있게 돕습니다.

  • 복약 시간 알림
  • 버튼·센서 기반 복약 이벤트 기록
  • 미복용·지연 복용 관찰 로그
  • 보호자 확인 알림
  • 기기 연결·배터리 상태 확인
  • 앱 연동
  • 사용 리포트
  • 가정 돌봄 테스트
