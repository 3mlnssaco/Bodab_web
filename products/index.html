01 / 개인 건강관리 · 기록의 출발점

UniQdata

UniQdata는 흩어진 건강기록을 개인 DB에 모아 관리하고, 일상에서 활용하는 개인 건강관리 서비스입니다.

DataQ는 원본과 출처를 보존하면서 반입·표준화 후보를 만드는 내부 단계입니다. MediQ와 MindQ는 UniQdata 안에서 열리는 인앱 경험입니다.

  • 건강기록 한눈에 보기
  • 일상 로그와 루틴
  • 진료 전 질문 준비
  • 동의와 접근 확인

MediQ: 진료 전후 기록 · MindQ: 마음·컨디션 일지

개인 통제 · 블록체인 기반 검증

공유의 기준은 개인에게.

UniQdata.io에서는 개인이 자신의 기록을 관리하고, 누구에게 어떤 기록을 공유할지 선택합니다.

SportiQue의 공유 아키텍처는 개인의 기록 보관, 동의와 권한, 블록체인 기반 증빙 검증을 분리합니다. 건강기록 원문과 복호화 키를 공개 원장에 올리는 방식이 아닙니다.

  1. 개인이 정하는 범위공유 대상·목적·기록 범위를 동의에 연결합니다.
  2. 권한에 맞춘 전달수신자의 권한과 키를 확인하고, 허용된 범위의 암호화 전달을 연결하는 설계입니다.
  3. 원문과 분리된 증빙동의·접근·공유 이력의 증빙을 배치로 묶고, 원문을 공개하지 않는 블록체인 검증 구조에 연결합니다.
  4. 철회와 이력 확인새로운 접근을 차단하는 철회와, 이미 남은 이력의 증빙 확인을 구분합니다.

02 / 동의 기반 연구 운영

UniQLab

UniQLab은 연구자와 기관이 연구 준비, 참여자 관리, 동의·반복 수집을 운영하는 워크스페이스입니다.

개인 앱과 달리 연구팀과 기관을 위한 업무 제품입니다. 반복되는 문서, 참여자 상태, 협업 흐름을 한 곳에서 보이게 합니다.

  • 연구 프로젝트 준비
  • 참여자 조건 관리
  • 동의 현황 확인
  • IRB 문서 보조
  • 기관·연구자 권한
  • 데이터 접근 기록
  • 방문 일정 확인
  • 운영 리포트

개인 통제 · 블록체인 기반 검증

공유의 기준은 개인에게.

UniQLab.io에서는 참여자가 동의한 연구 목적과 범위 안에서 기록을 연결합니다. 기관 계정만으로 개인 기록에 접근할 수 있는 것은 아닙니다.

03 / UniQdata 기반 어르신용 앱

Bodab

Bodab은 어르신이 큰 글씨와 짧은 단계로 복약·일정·일상 체크인을 직접 관리하도록 돕는 앱입니다.

어르신이 공유를 허용한 기록은 가족이 UniQdata의 FamilyCare에서 동의 범위 안에서 확인할 수 있습니다.

  • 큰 글씨와 짧은 안내
  • 복약 일정과 본인 확인
  • 병원 방문 일정
  • 일상 체크인
  • 가족 공유 범위 선택

개인 통제 · 블록체인 기반 검증

공유의 기준은 개인에게.

Bodab에서 남긴 기록은 어르신이 허용한 범위 안에서 가족과 연결됩니다. 가족 공유와 기관의 돌봄 업무 권한은 구분됩니다.
