UniQdata는 흩어진 건강기록을 개인 DB에서 관리하는 출발점입니다.
같은 기반의 어르신용 앱 Bodab, 동의한 연구를 운영하는 UniQLab, 개발 중인 YAKSON PoC 등 주요 접점과 프로젝트를 소개합니다.

01 / 개인 건강관리 · 기록의 출발점

UniQdata

UniQdata는 흩어진 건강기록을 개인 DB에 모아 관리하고, 일상에서 활용하는 개인 건강관리 서비스입니다.

DataQ는 원본과 출처를 보존하면서 반입·표준화 후보를 만드는 내부 단계입니다. MediQ와 MindQ는 UniQdata 안에서 열리는 인앱 경험입니다.

  • 건강기록 한눈에 보기
  • 일상 로그와 루틴
  • 진료 전 질문 준비
  • 동의와 접근 확인

MediQ: 진료 전후 기록 · MindQ: 마음·컨디션 일지

02 / 동의 기반 연구 운영

UniQLab

UniQLab은 연구자와 기관이 연구 준비, 참여자 관리, 동의·반복 수집을 운영하는 워크스페이스입니다.

개인 앱과 달리 연구팀과 기관을 위한 업무 제품입니다. 반복되는 문서, 참여자 상태, 협업 흐름을 한 곳에서 보이게 합니다.

  • 연구 프로젝트 준비
  • 참여자 조건 관리
  • 동의 현황 확인
  • IRB 문서 보조
  • 기관·연구자 권한
  • 데이터 접근 기록
  • 방문 일정 확인
  • 운영 리포트
UniQLab 알아보기 ↗

개인이 연구 참여와 공유 범위를 선택한 뒤 연결되는 활용처입니다.

03 / UniQdata 기반 어르신용 앱

Bodab

Bodab은 어르신이 큰 글씨와 짧은 단계로 복약·일정·일상 체크인을 직접 관리하도록 돕는 앱입니다.

어르신이 공유를 허용한 기록은 가족이 UniQdata의 FamilyCare에서 동의 범위 안에서 확인할 수 있습니다.

  • 큰 글씨와 짧은 안내
  • 복약 일정과 본인 확인
  • 병원 방문 일정
  • 일상 체크인
  • 가족 공유 범위 선택

04 / 개발 중인 복약 보조 장치 PoC

YAKSON

YAKSON은 약봉투 배출과 사용자의 복용 확인을 구분해 기록하도록 개발 중인 복약 보조 장치 PoC입니다.

약을 처방하거나 실제 복용을 자동 판정하지 않습니다. 현재는 연결 약포의 이송·절단과 미수령 약포의 하단 보관 경로를 디지털로 검토 중입니다. 아래 기능은 개발 목표이며, 완성 외관과 실물 반복 시험은 아직입니다.

  • 복약 시간 알림
  • 버튼·센서 기반 복약 이벤트 기록
  • 미복용·지연 복용 관찰 로그
  • 보호자 확인 알림
  • 기기 연결·배터리 상태 확인
  • 앱 연동
  • 사용 리포트
  • 가정 돌봄 테스트
제품 문의하기 ↗
현재 기구 동작 검토 보기 ＋

미수령 약포를 하단에 보관하고 다음 회차 한 봉을 제시하는 경로를 살핀 디지털 후보입니다. 완성 외관·실물 반복 작동·제조 적합성은 검증 전입니다.
